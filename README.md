One newly coined English word, with a single-line definition: **Tablapse** — the instant blank when a new tab opens, wiping out why you opened it. It names the blank everyone gets when a fresh tab opens and the reason for opening it is already gone: *tab* + *lapse*, a brief failure of memory, so it reads, sounds, and sticks like a word English already had — two clean syllables, spelled exactly as it sounds, and *lapse* fits the moment better than *amnesia*, which is a medical condition rather than a second-long blank.

## Run it

```bash
python3 main.py
```

This prints the entry and writes it to `/output/entry.txt`.
